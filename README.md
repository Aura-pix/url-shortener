# URL Shortener

A small URL-shortening API built with Rust, Axum, and Tokio. It accepts a
validated HTTP(S) URL and returns a short link that redirects to the original.

This repository was created to test documentation tooling and documentation
updates. See the [API documentation](docs/api.md) for endpoint details.

## Run locally

```sh
cargo run
```

The server listens on `http://localhost:3000`.
